# 张浩鑫 · 3D 建模作品集（网页版）

## 怎么看

双击 `index.html` 就能打开，不需要装任何东西、不需要联网。

- 点任意一张图 → 放大
- 放大后：`←` `→` 翻页，`Esc` 关闭，手机上左右滑
- 每个作品右上角有「贴图 / 低模·布线」切换

## 怎么发给别人

**方式一：直接发压缩包**
把整个 `web` 文件夹打包成 zip 发过去，对方解压后双击 `index.html` 也能看（图片都在 `assets/img` 里，路径是相对路径）。

**方式二：挂到网上（推荐）**
这是个纯静态站点，只要把整个文件夹传上去就行，不用服务器、不用数据库：

| 平台 | 操作 |
|---|---|
| GitHub Pages | 新建 repo → 上传这些文件 → Settings → Pages → 选 main 分支 |
| Vercel / Netlify | 拖整个文件夹到网页上传区，几秒出地址 |
| 阿里云 OSS / 腾讯云 COS | 开静态网站托管，上传后得到 `xxx.oss-cn-...aliyuncs.com/index.html` |
| 图床类（如 Cloudflare Pages） | 同上，免费且带 HTTPS |

拿到网址后可以做成二维码印在简历上，或直接发链接给 HR。

## 想改内容

- **改文字**：打开 `index.html`，中文直接搜对应句子改
- **换图**：把同名文件放进 `assets/img/` 覆盖即可（建议宽度 1500px 以内、JPEG）
- **加作品**：复制一个 `<section class="work">…</section>` 整段，改 `id`、标题、图片路径；同时在顶部导航加一个 `<a href="#新id">`

## 体积

首屏只加载封面图，其余图片是懒加载（`loading="lazy"`），所以打开很快。
整站 4.9MB，其中封面 1.1MB。
